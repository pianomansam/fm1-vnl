# FM-1 firmware screens: a catalogue

The screenshots themselves are other projects' images, kept locally only (git-ignored) in
`app/build/research/fm1-screens-2026-11-06/`; each repo's `.urls` file there lists where they came from.

Studied 2026-11-06: about 45 firmwares, roughly 260 screens (README images, docs folders, composite "screens" sheets, manual maps). Stars (★) are GitHub stars as of today. Source code was not read. Many firmwares descend from the Felucca base (the "Felucca house style" below), so its conventions are what most FM-1 owners already know.

Top 10 studied by stars: JIANT 214, clipper-fm1 78, fm1-loom 66, zp12 35, grimm 35, fmini-1 31, Ravel_FM1 25, caravel 23, Fart-Machine-One 23, fm_lab 21. (The two biggest repos, fm1-custom-fw 383 and fm1_open 313, are a hub and the vendor SDK, not firmwares with screens.)

## 1. What's possible

### Layout
- **Status bar, ~14 px, top.** Track chip (colored "1"/"T1"), rec dot, play triangle, metronome and tempo, OCT, battery. Felucca house style: clipper-fm1 78★, sloop-pro 8★, GammaWave-FM1 10★, caravel 23★, Kitten-Synths 5★, JIANT 214★, FM1-MOVE 15★. Variants add a button badge naming the active section (fm1-loom 66★ `HOME`/`SEQ`/`EDIT`; grimm 35★ `SEQ`/`FX`; fm1-rocket-os 2★ `STUDIO`/`LIVE`), "unsaved" and scene (fm1-loom), Q/G quantize-groove lamps (FM1-MOVE).
- **4-knob strip.** Four equal cells, each with a label (often with a tiny icon), a big value and a thin fill bar under it. At the top (Felucca family, Ravel_FM1 25★, JIANT, GammaWave) or the bottom (PERF-1 13★, fm1-loom, FM1-MOVE, elixir 10★, zp12, rocket-os, hera-fm1). Nearly universal: about 38 of 45.
- **2×2 zoom.** The same four values repeated huge under the strip (sloop-pro, clipper-fm1, Kawa-Tracker 9★).
- **Section tabs.** A row of page names with the active one lit (JIANT `PATT TRACK BAR STEP AUTO`; fmini-1 31★; elixir `AMP VOICE GLOB`). PERF-1 squeezes every section into one letter tab (`T P B A L D R S M G J`), with the active one widened and colored.
- **Lists.** A highlight bar on the selected row, scrollable with the select encoder (preset browsers in mc-1 7★, K-WASUB 5★, sloop-pro, caravel; settings lists in hera-fm1, rocket-os).
- **Tiles and grids.** Button-like tiles for keys, kits and FX (sloop `KEY`/`PUNCH`/`ERASE`; PERF-1's FX map; GammaWave drum pads).
- **Modal overlays.** A rounded card over a dimmed page: knob-turn value (rocket-os "LIVE" dial), undo/redo bar (K-WASUB), "NEXT BAR: CLIP 2" pill (FM1-MOVE), "STEP 3 · RATCHET 3 HITS" toast (K-WASUB), explanatory help card (fm1-loom, rocket-os).

### Visualizations
- **Step grids:** drum-lane × 16 grid (mc-1, chipbox 7★, LCD-4 4★, K-WASUB, rocket-os); a mini-grid per track row (clipper, sloop, Kitten, mono2k 18★); dots and rings (K-WASUB, grimm).
- **Piano roll / note bars:** sloop-pro, FM1-MOVE, JIANT `BAR`, chipbox.
- **Envelopes, LFO shapes, filter curves:** drawn live as the knob moves (Ravel, sloop-merthsoft, fm1-loom, K-WASUB, GammaWave, fmini-1).
- **Scopes and waveforms:** caravel, fm_lab 21★, GammaWave (spectrogram), fm1-studio.
- **Meters and mixers:** vertical faders per part with mute/solo (FM1-MOVE, mc-1, PERF-1, vesper 1★, sloop `MIX`, chipbox, Ravel); level meters (PERF-1 `PBACD`, LCD-4, GammaWave).
- **Generative/"brain" views:** PERF-1's radar (chord name such as Am7 in a circle of the pattern's steps); JIANT `ECO` creatures that dance with the parts; grimm's eye; hera-fm1's big chord name; fm1-loom's "follow" page (which tracks follow the chord).
- **Characters and scenes:** JIANT, BOP-1 2★, LCD-4 (pixel band), Fart-Machine-One, CINCO, mope-1 (a mood face), zen-1, gnomad 6★, Paleotone 9★.
- **Progress:** song or arrange bar (JIANT `ARRANGE`), circular bar counter (FM1-MOVE "1 OF 1"), count-in digit (sloop, clipper).

### Typography and color
- Usually **two to three sizes**: a 7–9 px label size, a 14–16 px value size, and one display size for the hero value (tempo, page title, chord). Pixel fonts dominate; anti-aliased sans (fm1-loom, FM1-MOVE, gnomad) reads as more premium.
- **Color = track identity.** One stable color per track or part, reused on chips, grid cells, faders and tabs (sloop, clipper, FM1-MOVE, PERF-1, chipbox, rocket-os). Accent color = the focused control.
- **Inverse bars** for selection (mono2k, mc-1, hera-fm1). **Palettes/themes** the user can switch (caravel's five, Golana, PERF-1).
- **Icons:** tiny glyphs before knob labels (Felucca family), button-cap badges in hints (fm1-loom).

### Navigation conventions
- **Hardware button = section; select encoder = page within it.** JIANT states it as rules: "SELECT walks the pages", "the button: in, or on", "hold = the layer", "PRESETS loads presets", "the screen says where". fm1-loom, Ravel and K-WASUB follow the same model.
- **HOME** = the main or perform screen; holding it opens a menu or combos (JIANT menu, rocket-os "hold HOME: combos"). **EDIT** = the sound engine of the current track. **GLO** = global (tempo, mixer, MIDI, system). **ALGO encoder = track select** (Ravel, loom, sloop-pro, JIANT). **PRESET encoder = browse** (sounds, patterns, kits).
- **Page indicator:** `n/m` (sloop, JIANT `1/7`), dots (fm1-loom, Ravel), or a dashed row of segments (caravel).
- **Breadcrumb footer:** `T1 › DRM-KICK › HOME 1/2` (mono2k), `T1 kit › P1 › S1` (fm1-loom), `HOME · ECO` (JIANT).
- **Hint line** naming what the buttons do now, in key-cap badges: fm1-loom, rocket-os, gnomad, hera-fm1, Ravel, PERF-1.

### Feedback
- **Knob-turn popup:** the focused cell lights up, or a big overlay appears (rocket-os, sloop `PRESETS` popup that closes after 500 ms).
- **Toasts:** undo, "next bar", battery low (FM1-MOVE, K-WASUB, rocket-os).
- **Transport:** play/stop glyph, `bar.beat` (sloop `1.4`), a 4-dot beat counter, tempo always visible.
- **Recording:** red dot, red `REC READY`, count-in, red frame around the page (rocket-os).
- **CPU and voices:** PERF-1 `CPU 0 XR 0`, tastywaves `V 3/12 CPU 0%`, ptfm 11★ status page, fm1-yoga `CPU 0% XRUN 0`.

### Special
- **Screen reader:** fm1-reader sends screen text over USB to a web page that speaks it; it is built into fm1-base and used by fm1-boardwalk and others. Rare, but VNL-1 inherits it from fm1-base.
- **Help:** help cards (rocket-os, fm1-loom), HOME+LFO help (ptfm), printed nav maps (JIANT, gnomad, GammaWave cheat sheets).
- **Splash/boot:** logo card (sloop, Golana, tastywaves, Paleotone).
- **Save/load:** name entry with a character grid (mope-1), slot grid (sloop `SONG`, gnomad "MINE 1–4"), A–D sections (JIANT).
- **Settings:** a plain list with right-aligned values (hera-fm1, rocket-os `LIVE SETUP`, fm1-yoga).

## 2. Main / home screens

Most homes are a **track overview with the 4 knobs bound to global or groove values** (swing, level, steps, pan; or tempo, groove, amount, pattern). The rest are a **hero visual** (creature, radar, scope) with the knobs bound to sound macros. They lead deeper in three ways: a section button, ALGO to change track, or SELECT to step through pages.

## 3. Groovebox layout specifically

- **Main:** 4–8 track rows: color chip, name and engine, mini step strip with playhead, level bar (clipper, sloop-pro, Kitten, mono2k, ptfm). Clip-matrix variants: rows are roles (DRUM BASS LEAD CHRD FX), columns are clips A–D (rocket-os, FM1-MOVE). fm1-loom's arrange page shows 8 tracks plus CO (chords) and TH (theme) lanes, each with its pattern and a level dot, and a big scene number.
- **Track/part pages:** the same header, the strip for that part's four values, a visual in the middle, and the part's name and page number in the footer. ALGO switches the part while you stay on the page (Ravel, loom, JIANT).
- **Mixer:** one fader per part in part colors, M/S under each, knobs set volume/pan/send for the focused part (FM1-MOVE, mc-1, PERF-1, vesper). Usually under GLO.
- **Transport:** PLAY toggles, REC arms with a count-in, "next bar" quantized launches shown as a toast or pill.
- **Generative ones** (PERF-1, JIANT GEN, hera-fm1, loom conductor) put the musical state in words: key/mode, chord name, "PATTERN 1", "EVOLVE 40 · MOTION 60 · DRIFT 45S" on the four knobs.

## 4. Implications for VNL-1

**Conventions users will expect**
- HOME = the song/perform screen. Holding HOME opens a menu. EDIT = the current part's sound. GLO = global (tempo, mixer, system). ALGO = which part. PRESET = browse. SELECT = page within a section.
- A status bar with play state, bar.beat and tempo; a 4-knob strip whose labels always match what K1–K4 do; one color per part, used consistently everywhere.
- Page `n/m` or dots, plus a short hint line.

**Ideas for a generative song player**
- Home as a "what was rolled" card: key/mode, current chord in large type, section (INTRO/A/B) with a progress bar through the song, part chips (DR BS CP PD LD TX) lit when playing. Almost nobody shows key, chord or song position on home, so this would set VNL-1 apart.
- Knobs on home bound to song-level macros, as PERF-1 does (EVOLVE/MOTION/DRIFT), not synth parameters.
- Per-part pages reached with ALGO, with the same skeleton on every part; a small "reroll this part" affordance.
- A "next bar" pill for queued changes; screen-reader text for free from fm1-base.

**Hard on 240×240**
- More than 6 track rows plus a knob strip becomes unreadable; 4–6 rows is the practical limit.
- Text under 7 px; long chord symbols (`C#m7b5(11)`) in the big font.
- Mixing a hero visual and a track list on one page. Pick one per page; PERF-1's radar plus meters is near the ceiling.
